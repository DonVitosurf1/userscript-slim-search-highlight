# Sicherheit

Slim Search Highlight läuft als Userscript auf den Seiten, die du besuchst. Sicherheitsprobleme bitte
nicht öffentlich als Issue melden, sondern über
[GitHub Security Advisories](https://github.com/DonVitosurf1/userscript-slim-search-highlight/security/advisories/new)
(Reiter „Security“ → „Report a vulnerability“).

Unterstützt wird jeweils die aktuelle Version auf `main`.
