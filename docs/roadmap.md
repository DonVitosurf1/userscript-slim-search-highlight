## Website-Suche und Schnellsuche · 4.8.0

- [x] Kompakte Seitensuche mit Live-Markierungen, Trefferzahl und Vor/Zurück ergänzen.
- [x] Ganze Wörter, Groß-/Kleinschreibung, unmittelbares Leeren, Escape/Fokus-Rückgabe und „+ Markieren“ umsetzen. Die Vorschau bleibt vorübergehend; übernommene Begriffe werden zunächst nur Seitenmarkierungen.
- [x] `Strg+Shift+F` sowie einen sichtbaren Öffnen-Button ergänzen; Shortcut aufzeichnen, zurücksetzen oder deaktivieren können.
- [x] Interne Website-Suche pro Website aktivierbar machen: URL-Suchparameter, bestätigte Suchformulare, Ergebnislinks innerhalb derselben Website und dynamische Seiten unterstützen.
- [x] Herkunft „Website-Suche“, stabile Farben, getrennte Speicherung, Hell/Dunkel, Transparenz und zugängliche Tastaturbedienung integrieren.
- [x] Funktions-, Sicherheits- und Browserprüfungen bestehen; Dokumentation und Screenshots aktualisieren und Version veröffentlichen.

Die Schnellsuche verändert keine vorhandenen Markierungen. Website-Suchen werden nur nach ausdrücklicher Aktivierung für die aktuelle Website übernommen; Suchanfragen werden nicht als dauerhafte Keywords gespeichert.
